# medi-plus-posts

Обложки и тексты постов для группы ВКонтакте стоматологии «Меди+» (vk.ru/centrimplant).

- `YYYY-MM/post_DD.jpg` — обложки, `YYYY-MM/posts.json` — тексты постов.
- `tools/make_covers.py` — генератор обложек (Playwright + Chromium). Новые темы добавляются в `scene()` и список `POSTS`.
- Публикация: страница группы в Chrome забирает картинку отсюда (raw.githubusercontent.com) и ставит пост на таймер.

Правила для текстов: в конце — подпись врача, телефон 8 (911) 211-11-30 и строка «Имеются противопоказания. Необходима консультация специалиста.»; посты Исмата и Шамиля чередуются; без неподтверждённых превосходных оценок.
